# Contracts to use
Start with member2/FINAL-CONTRACTS.md and the three *.openapi.json files for implemented endpoints.
member2/schemas and member2/examples describe the agreed payloads. UUIDs in examples are fictional: replace them with IDs from your own application, verification and workflow. Sample money is illustrative, not a promise of a fixture's calculated result.
events contains the shared event envelope and workflow schemas used for integration. Financial mock examples are in requests/member2.http. The final financial response deliberately differs from the earlier financial draft: use the implemented FINAL document.
